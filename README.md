# quiz-app

Веб-застосунок «Вікторина зі збереженням результатів» (Варіант 8).
Практична робота з дисципліни «Програмування веб-застосувань».

## Звіт з аудиту безпеки

### 1. XSS-аудит

- **Вразливе місце:** Відображення тексту питань та відповідей, отриманих від API.
- **Вектор атаки:** Впровадження тегу `<img src=x onerror="alert('XSS')">` у текст питання.
- **Усунення вразливості:** Замінено використання директиви `v-html` на безпечну інтерполяцію `{{ question }}` (аналог
  `textContent`), що унеможливлює виконання сторонніх скриптів.

### 2. Сховище даних (LocalStorage / IndexedDB)

- У локальному сховищі зберігаються лише технічні прапорці та результати квізу (дата, score). Персональні дані відсутні.

### 3. HTTPS та секрети

- Приватні ключі в коді відсутні. Розгортання виконується на хостингу з HTTPS за замовчуванням.
